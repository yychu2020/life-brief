一份给自己的阶段手记

先写清来龙去脉，
再问 AI 怎么做。

大模型能帮你理思路，了解你的经历、目标和现实限制后，建议也更容易落到实处。用生活折页把背景写成手记，下载 .md，再交给你常用的 AI。

免登录。填写、生成和下载手记都在浏览器内完成，生活折页不会收到你的答复。

怎么用

  1. 写下自己的背景

    从近况写起，再挑相关的经历、技能和限制补充。

  2. 下载 Markdown 手记

    检查整理出的内容，保存为 .md 文件。

  3. 带着背景问 AI

    上传文件或粘贴愿意分享的内容，问它该先做什么、技能还能用在哪，或上一阶段有哪些经验。

    隐私承诺

    你的填写内容只在当前浏览器里处理。生活折页不会收集或上传你的答复、手记、自测结果和财务记录。

    • 使用与保存。免登录，页面没有分析追踪。草稿和主动归档的自测结果由浏览器保存，你可以在页面清除。下载的 Markdown 和 CSV 文件由你保管。
    • 公开网页。公开版由 GitHub Pages 托管。GitHub 可能处理提供网页所需的访问信息，例如 IP 地址。
    • 主动分享。把文件交给其他工具、在 GitHub 公开反馈或使用支付宝时，相关内容按你选择的服务处理。
